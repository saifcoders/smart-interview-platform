# Screenshot Capture Plan

A guide outlining the key screens to capture for creating a professional project portfolio, GitHub README gallery, or slide deck presentation.

---

## 1. Landing & Authentication Flow
1. **Landing / Login Page**:
   * *Capture*: The main entry portal showing clean, styled Tailwind input fields for Email and Password, and links to Registration.
2. **Registration Validation**:
   * *Capture*: An invalid format validation error (e.g. malformed email or short password alert banner) displaying inline feedback.

---

## 2. Student Practice Dashboard
3. **Student Dashboard (Initial State)**:
   * *Capture*: The dashboard view showing empty stats widgets (Quizzes Attempted: 0, Mock Interviews: 0, Interview History: "No sessions found").
4. **Quiz Selection Page**:
   * *Capture*: The listing grid of available quizzes with tags (e.g., Java Basics) and start buttons.
5. **Active Quiz Taking Interface**:
   * *Capture*: The interactive quiz layout showing single-question paging, multiple choice radio select options, and countdown timer.
6. **Quiz Grading Result**:
   * *Capture*: The results display showing computed scores, percentage metrics, and a success banner.
7. **Student Dashboard (Populated State)**:
   * *Capture*: The dashboard stats populated with historical quiz records and attempted interview counts.

---

## 3. AI Practice & Interview Module
8. **AI Mock Interview Configuration Page**:
   * *Capture*: Selection options for mock categories (e.g., Java, System Design, Behavioral).
9. **Active AI Interview Turn-by-Turn Interface**:
   * *Capture*: The split screen showing the current question generated by Gemini on the left, the user response textbox on the right, and the "Submit Answer" button.
10. **Structured Real-Time AI Feedback**:
    * *Capture*: The instant feedback popup or sidebar showing AI Score (0-10), candidate strengths, weaknesses, and omitted concepts.
11. **Final Interview Evaluation Report**:
    * *Capture*: The finished interview view containing average category score, overall technical summary report, and complete turn history transcript.

---

## 4. Administration Controls
12. **Admin Statistics Dashboard**:
    * *Capture*: The `/admin.html` page showing global counts of Questions, Users, and Quizzes.
13. **Admin Question CRUD**:
    * *Capture*: The question management panel, showing search, edit modal, and new question forms.
14. **Admin Quiz Constructor**:
    * *Capture*: The quiz creation window showing the interactive checkbox checklist where questions can be linked into a new quiz set.
